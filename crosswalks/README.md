# Crosswalks

Crosswalks map the Data Product Operating Framework to relevant external standards and frameworks.

Candidate crosswalks include:

- DCAM
- DAMA-DMBOK
- COBIT
- NIST AI RMF
- ISO/IEC 42001
- ISO 37301
- ISO 8000 family
- ISO/IEC 27001
- TOGAF

A crosswalk should identify:

- source framework element
- mapped DPOF function
- mapped DPOF capability
- relationship type
- notes
- evidence implications
