# Enrichment Briefs

Briefs are maintainer-authored research questions that define a target, purpose, scope and exclusions before retrieval or drafting. A brief should state whether the expected result is an editorial clarification, implementation guidance, profile strengthening, crosswalk or proposed normative change.

Briefs are optional and non-normative. Keep durable briefs here when they help explain a material change; use the command-line arguments for small investigations.
