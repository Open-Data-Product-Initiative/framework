# AI-Agent-First scenario

This lighter synthetic scaffold covers a customer-support agent answering a governed business question. The agent discovers candidate products, reads the authoritative contracts, resolves vocabulary, traverses allowed relationships, checks its purpose-bound access, verifies version and current assurance evidence, and follows a permitted workflow.

The agent must stop and escalate when vocabulary is ambiguous, access is denied, the contract is stale, quality is failed, a relationship is missing or human approval is required. Its output includes the products, versions, graph path, checks performed and escalation evidence. It does not receive unrestricted autonomous access.
