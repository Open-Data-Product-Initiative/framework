# Examples

Examples show how the Core, detailed capability reference and implementation playbook fit together. They are not normative specifications and use synthetic organisations unless a source says otherwise.

- [Customer 360 complete chain](customer-360/README.md) is the fully worked scenario with ODPS, ODPC, ODPG, ODPV and ODPR artifacts plus separate declared, observed, control and value evidence.
- [Regulated finance](regulated-finance/README.md) is a scaffold for stricter access, policy, lineage, control and assurance discussion.
- [AI-Agent-First](ai-agent-first/README.md) is a scaffold for safe machine discovery, permission checks, stop conditions and human escalation.

The source artifacts are copied into the generated publication so they can be inspected beside the documentation. Example validation uses the available ODPS 4.2 schema and the locally inspected ODPC, ODPG, ODPV and ODPR 1.0 SDK schemas.
