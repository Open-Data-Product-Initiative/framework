# Declared state

The following commitments and controls are a framework example. The ODPS 4.2 artifact remains deliberately limited to fields verified against its schema; this document does not claim to add runtime-evidence fields to ODPS.

| Declaration | Value | Owner |
|---|---|---|
| Completeness | At least 98% per scheduled evaluation | Product owner |
| Freshness | No more than 60 minutes | Service owner |
| Availability | At least 99.9% monthly | Service owner |
| Contract version | 2.4.0 | Product owner |
| Access | Approved consumers only | Access owner |
| Production release | Human approval required | Release approver |

## Access

The retention analytics group may request approved read access for the registered churn-risk use case. Discovery of the catalog reference does not grant access.
