# Regulated finance scenario

This lighter synthetic scaffold uses a regulatory-reporting product. The product has restricted visibility, purpose-bound access, an approved reporting calendar, lineage to upstream source products, a control mapping and retained evidence of review and release approval.

Use it to test C6 through C13: which reporting rule applies, who may access the data, which dependencies affect a filing, which version was used, which controls operated and how an exception is approved. The framework does not claim that an ODPS contract alone proves regulatory compliance.
